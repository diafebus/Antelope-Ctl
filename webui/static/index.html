Meter debug

Live raw bytes, offset labelled, movers ringed. Scale is inverted (96 = silence, → 0 as it gets louder). Feed one input at a time with outputs muted and watch which offset moves — that's the real map. See webui/METERS.md.

Routing

One destination at a time; rows are sources (click a group to expand). Each output channel takes exactly one source — click an empty cell to route it, click the lit cell to mute. Read-modify-write of the whole group (readback cat 0x03), like the Launcher: no "unroute", only replace or mute. A write flashes green when the device confirms, red if it comes back different.

Protocol readback

Profile-declared nested records from the device's read-only 0x74/0x75 protocol. Safe outer indices are refreshed in the background; schema-only layouts stay marked capture-required. Link bytes remain observational unless the active profile marks their mapping capture-confirmed; a complete confirmed mixer bitmap may seed its pair buttons.
